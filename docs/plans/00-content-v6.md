### 00.4 — Правила светофора v1

`docs/content/rules-v1.md`, по сигналам (см. [architecture §6](../architecture.md#6-светофор)):

- **Сон:** зелёный ≥ 7 ч; жёлтый 6–7 ч; красный < 6 ч. Sleep Score ≥ 75 — опционально.
- **RHR:** от baseline (медиана 28 дней): жёлтый +4–6, красный ≥ +7 два дня и больше.
  Стартовый baseline 48 → ≤ 51 / 52–54 / ≥ 55 два дня (абсолютные ≤ 54 из v5 отменены, D14).
  Итоговая версия правил — [rules-v1.md](../content/rules-v1.md), она главнее этого конспекта.
- **HRV:** в коридоре / ниже 1–2 дня / ниже 3+ дней.
- **Желание двигаться, ноги:** 3 уровня.
- **Колено, бедро:** 0–1 / 2–3 / ≥ 4 или боль в покое.
- **Энергия:** пока не входит в итог, только отображается (пересмотреть после гейта).
- **Итог:** по худшему известному сигналу; один жёлтый при остальных зелёных не учитывается.
- **Подмены:** зелёный — по плану; жёлтый — интенсивная → лёгкий бег, силовая → Lite;
  красный — отдых или прогулка.
- **Красные флаги вне светофора:** перебои не проходят на шаге, боль или давление в груди,
  предобморок, одышка не по нагрузке → стоп и к врачу.
- Шаблон недели Пн–Вс из v5 как план по умолчанию.

### 00.5 — Правки ревью (принятые)

- [ ] Сон — KPI №1 энергии; иерархия: сон → энергия → RHR/HRV → тренировки
- [ ] Кардио не наращивать: 250–400 — цель, а не минимум
- [ ] Две силовые — фундамент; третья зимой только при хорошем восстановлении
- [ ] Силовые A/B укоротить до реальных 40–45 мин: ядро 5–6 упражнений, аксессуары — суперсетом или по очереди
- [ ] Разгрузка по светофору (~раз в 4–8 недель), а не каждые 4 недели
- [ ] Интенсивность — инструмент; RPE/LTHR > мощность > темп
- [ ] Светофор от личного baseline
- [ ] Подвижность 3–6 раз в неделю
- [ ] Движение в рабочий день: стоять ≠ двигаться
- [ ] Горизонт 80: функция → способности → тесты и тренировки
- [ ] Медицина: HBsAg + anti-HBs + total anti-HBc; нагрузочная ЭКГ — не «лицензия на Z5»
      (холтер — см. пункт «Перебои» ниже)
- [ ] 40 отжиманий — бенчмарк, а не граница здоровья
- [ ] LTHR 165: пересчитать зоны и темпы во всём тексте (лёгкий бег < 151, 4×4 > 165)
- [ ] RHR: ориентир «~52 и ниже» → личный baseline ~48; пороги светофора из `rules-v1.md`
- [ ] Перебои: «нагрузочно-зависимые экстрасистолы» → «редкие перебои в покое, на фоне
      болезни, недосыпа или стресса; с нагрузкой не связаны». Медицинский блок: ЭКГ покоя
      и нагрузочную оставить; вместо «холтер в тренировочный день» — обсудить с
      кардиологом, как поймать редкий эпизод (длительный патч-монитор или запись ЭКГ
      в момент перебоя)
- [ ] Движение днём: шаги 8–12 тыс. уже есть → акцент на перерывах в сидении, а не на шагах
- [ ] Сон: стартовое среднее 6:55 при потребности 7:02 → сон остаётся KPI №1

### 00.6 — Научные формулировки

Каждую проверить по первоисточнику, прежде чем писать.

- [ ] VO₂max: убрать «−10 %/десятилетие, у тренирующихся вдвое медленнее» как закон
- [ ] Хрящ: убрать «только через синовиальную жидкость»
- [ ] Углеводы: вокруг активности и равномерно; без большого позднего ужина
- [ ] Фруктоза и DNL: значимы при больших дозах свободных сахаров и калорийном избытке
- [ ] Поджелудочная: причина — переносимость, GERD, калорийность, а не «разгрузка железы»
- [ ] Лейцин: плавная зависимость доза–ответ; ориентир 30–40 г белка × 3–4
- [ ] Омега-3 и AF: метаанализ 2025 — проверить; сигнал при > 1,5 г/сут у высокого CVD-риска
- [ ] ИПП: B12 и Mg — не рутинно (AGA — проверить), а при факторах риска
- [ ] Креатин: baseline креатинин/eGFR, при путанице — цистатин C

## Цель

План v6 живёт в приложении и связан с экранами: из любого решения можно открыть «почему».

**Критерий готовности:** артефакт больше не нужен для ежедневной работы; числа в тексте
совпадают с настройками.

## Скоуп

**Входит:** контент, связи через frontmatter, подстановка значений.
**Не входит:** граф System Map (бэклог), таблица `knowledge_articles` (D10).

- [ ] Все ссылки «почему» ведут на существующие якоря

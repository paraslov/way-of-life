## Цель

Занести контрольную пробежку или поход из файла Garmin за несколько касаний, не
переписывая цифры руками, чтобы видеть прогресс по одному протоколу.

**Критерий готовности:** файл easy 5 км превращается в контрольную сессию с темпом,
средним пульсом и отрезками; повторный импорт того же файла ничего не дублирует; файл
после обработки нигде не хранится.

## Связь с моделью

- **Ось:** Capacity — аэробный резерв.
- **Решение и горизонт:** квартал/десятилетие — растёт ли резерв, стоит ли менять баланс лёгкой и интенсивной работы.
- **Функция в 80:** «4 этажа без остановки», «неровная тропа».
- **Соблазны:** копия Garmin (карты, каждый сплит, посекундный пульс), автоимпорт всего подряд, score формы — не делаем.

## Скоуп

**Входит:** ручная загрузка файла одной активности, предпросмотр, сохранение в `activities`
(как обычная или контрольная сессия), сопоставление с ручной записью.
**Не входит:** импорт сна, RHR, HRV и других дневных метрик (бэклог, только если гейт покажет
необходимость); Garmin Health API и неофициальные клиенты с логином в Garmin Connect;
массовый импорт истории.

## Данные

- **Каноническое хранение:** `activities` + детали 03 ([architecture §4](../architecture.md#4-data-provenance-and-deduplication), [§11](../architecture.md#11-benchmark-sessions-d24)). Второй серии нет.
- **Источник:** `source = 'garmin'`, `external_id`. Отредактированные в предпросмотре значения — канонические; сырые данные файла не хранятся.
- **Пусто ≠ 0:** поле, которого нет в файле (например, пульс без датчика), остаётся пустым.
- **Режимы недели:** не влияют на импорт; импортированная сессия учитывается в неделе как обычная.
- **История:** средний пульс и темп хранятся как есть и от LTHR не зависят. Откат — удалить активность; отдельная `import_batch` не нужна, пока импорт по одному файлу.

## Ограничения

- Файл читается в памяти запроса и не сохраняется ни на диске, ни в БД, ни в логах.
- Учётные данные Garmin приложение не запрашивает и не хранит.
- Значения здоровья не попадают в логи и URL.

## Проверка

- [ ] Повторный импорт того же файла не создаёт дубль
- [ ] Импорт в день с ручной записью того же вида предлагает дополнить её
- [ ] Интервалы 4×4: сохраняются рабочие отрезки, средний пульс всей сессии не выдаётся за качество отрезков
- [ ] Файл без пульса или без GPS сохраняется с пустыми полями, а не нулями
- [ ] Файл не остаётся на сервере; логи без значений здоровья
- [ ] 375 px, светлая и тёмная тема

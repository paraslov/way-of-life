## Цель

Снять ручной ввод сна, RHR, HRV и активностей без дублей и без потери ручных правок.

**Критерий готовности:** повторный импорт того же файла ничего не дублирует; ручное
значение не затирается без подтверждения.

## Ограничения

- Официальный Garmin Health API — только при выданном доступе.
- Неофициальные клиенты (логин в Garmin Connect) — только осознанно: риск блокировки
  аккаунта, хранение учётных данных. Учётные данные Garmin не хранятся в приложении.
- Файлы импорта не сохраняются после обработки.
